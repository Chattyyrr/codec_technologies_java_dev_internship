# Java Internship Projects

This repository contains two independent Java web applications developed as part of my internship work.

Both projects demonstrate practical application development using Java, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Spring Security, Thymeleaf, and MySQL.

## Projects

### 1. Online Bookstore Management System

A web-based bookstore application that allows users to browse books, manage shopping carts, and place orders.

**Key Features**
- User registration and authentication
- Book catalogue and search functionality
- Shopping cart management
- Checkout and order placement
- Order history
- Admin book catalogue management

**Technologies:** Java 17, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Spring Security, Thymeleaf, MySQL.

[View Project](./online-bookstore)

### 2. Employee Management System

A web-based application designed to manage employee records and administrative operations.

**Key Features**
- Employee creation, viewing, updating, and deletion
- Employee search functionality
- Employee profile management
- Employment status management
- Role-based access control (ADMIN, HR, VIEWER)
- Secure authentication and authorization

**Technologies:** Java 17, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Spring Security, Thymeleaf, MySQL.

[View Project](./employee-management-system)

## Running the Projects

Each project is an independent Maven-based Spring Boot application.

1. Clone this repository.
2. Open either project directory in your IDE.
3. Configure your MySQL database credentials in the project's application configuration.
4. Create the corresponding database.
5. Run the Spring Boot application.

Refer to each project's README for detailed setup instructions.
